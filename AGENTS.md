# Granite-field

TradeMesh frontend is a **mobile mini-app** on **Microsoft Fluent UI** (`@fluentui/react-components`).

- Design for a phone in the hand: one column, 44px targets, short words, content width about 28rem.
- Stay URL-routed and full-width. Do not wrap the app in a 390px device frame.
- Use Fluent components and Griffel `tokens` first. Brand (MoMo yellow / navy / blue) belongs in the Fluent theme.
- Customer Trust uses the public trust API only. Do not call internal risk for ordinary users.
